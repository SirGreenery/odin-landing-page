Some Helpfulish Information

You can make custom borders like these squares with border-radius: 15 15 0 0;

border-radius reads from Top-Left, Top-Right, Bottom-Right, Bottom-Left

If you don't like naming every class something different, I think you can use the same name for redundant sections and just add :nth-child(#) in CSS"
